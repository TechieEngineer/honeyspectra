# AI handover

Continue honeypot-core V1, an isolated local cybersecurity lab. Read README.md and SECURITY.md first. Go: cmd/honeypot/main.go orchestrates config-driven loopback listeners; internal/config validates JSON-subset YAML, internal/protocols defines registry and HTTP/TCP models, internal/logger implements bounded async JSONL. Python: backend/app.py tails data files, classifies fictional scenarios and exposes REST/SSE; simulator.py produces fictional sessions; backend/static is a no-build SOC UI with pagination, replay and persistent theme. Go/Python tests and CI are included. Docker Compose is optional and not validated in the original build environment. Do not claim real protocol fidelity, malware capture, real IP geolocation, production readiness or measured latency. Future priorities: improve schema validation, disk retention, end-to-end tests, benchmark 50k records, accessibility, signed releases and review isolation. Keep the lab local; use synthetic data for demonstrations. Preserve Git history and update README and tests with each change.
