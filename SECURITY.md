# Security policy

This repository is an educational local-only lab. Do not expose its listeners or dashboard to the internet or untrusted networks. Do not use real credentials or malware. Report vulnerabilities privately through the repository owner's preferred channel; do not publish secrets or exploit artifacts.

Bounded connections and queues reduce resource use but do not guarantee availability. Logs grow on disk and require manual retention. The dashboard has no authentication and must remain local. Container settings are defense in depth, not proof of containment; no cloud deployment is supported.
